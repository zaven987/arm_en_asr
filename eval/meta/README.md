# eval/meta — evaluation metadata (committed)

Audio is not committed (D18). Each CSV here describes clips whose WAVs live in gitignored folders.

## fleurs_hy_am_test100.csv

- Source: **FLEURS** (Google), `google/fleurs` on Hugging Face, revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd`, hy_am and en_us test splits.
- Licence: **CC-BY 4.0** — https://creativecommons.org/licenses/by/4.0/
- Paper: Conneau et al., "FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech", 2022, https://arxiv.org/abs/2205.12446
- Changes made by us: selected 100 sentences (rule below); Armenian and English text copied unchanged from the `raw_transcription` column; audio converted from 32-bit float to 16-bit PCM WAV (D18).
- Selection rule (D19): first 100 hy_am test sentence ids in TSV order that also appear in en_us test, one recording per id (the first hy_am row for that id).
- Columns: D18 columns `start,end,device,speaker,armenian,english` plus `fleurs_id` and `wav` (path of the PCM copy, relative to the repo root). `start` is always 0.00, `end` is the clip length, `device` is `mic` and `speaker` is `Me` (one reader per clip).
- Generated by `python scripts/fetch_fleurs.py`; do not edit by hand.
